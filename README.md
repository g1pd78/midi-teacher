# MIDI Teacher

Десктопное приложение для обучения игре на фортепиано с цифровым пианино
и MIDI-клавиатурой: интерактивный нотный стан, тренажёр чтения нот,
разучивание пьес с постепенным отключением подсказок.

- План продукта и этапы: [docs/PLAN.md](docs/PLAN.md)
- Техническая архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Чеклисты приёмки: [docs/checklists/](docs/checklists/)

**Готово:** этап 0 (подключение инструментов, маршруты звука, встроенный
рояль через ASIO/WASAPI, мастер первого запуска), этап 1 (тренажёр чтения
нот: 9 ступеней, адаптивный подбор нот, прогресс в SQLite) и этап 2
(интерактивный нотный стан: библиотека MusicXML, режим ожидания, руки
отдельно, вторая рука от приложения), этап 3 (падающие ноты, темп, цикл
по тактам, режим ритма с оценкой, отсчёт и метроном) и этап 4 (движок
практики: режим «Разучить» с фрагментами и уровнями подсказок до игры
по памяти, экран «Прогресс», тепловая карта трудных тактов), этап 4а
(аппликатура: палец у каждой ноты из файла, ручная правка или
автоматический подбор; на стане, в падающих нотах и на клавишах) и этап 5
(упражнения ступенями с оценкой ровности ритма и громкости, разминка дня,
«Занятие на сегодня», карточки теории и справочник, 11 встроенных пьес) и этап 6
(MIDI-файлы как пьесы: окно дорожек, умное деление на руки с правкой, нотный стан
с выравниванием по сетке, аккомпанемент; сохранение в MusicXML, запись своей игры
в MIDI, транспонирование любой пьесы). Гитара и бас (этап Г0): вход звука (Real Tone Cable
или звуковая карта), прослушивание себя с чистым звуком или лёгким перегрузом, тюнер,
калибровка задержки, запись входа в WAV; этап Г1+Г2 — любая пьеса на гитаре или басе в табах
с грифом и «дорожкой» по струнам, распознавание нот по звуку (все режимы работают), аккомпанемент
MIDI своими инструментами и барабанами (GM-банк GeneralUser GS). Этап «Б» — барабаны на пэдах
MIDI-клавиатуры: мастер назначения пэдов, ударный стан и дорожка по барабанам, грувы и рудименты
с оценкой ритма и силы удара, барабанная дорожка из MIDI как своя партия; запись своей игры прямо
в пьесе или упражнении (прослушать → сохранить). «Студия» — свой трек из дорожек: запись партий
поверх уже записанных, перезапись куска, дубли, микшер, выравнивание, трек из MIDI-песни с заменой
партий своими, экспорт в многодорожечный MIDI и WAV. Этап 7 (доводка): номер сборки и ссылка на новые сборки
в настройках, компактная панель пьесы (меню «⋯»), окно горячих клавиш («?» / F1), резервная копия
настроек, прогресса и треков студии в один файл. «Тренажёры»: кроме нот — чтение с листа (каждый раз новая
мелодия, 10 ступеней, подсказки убираются) и ритм-тренажёр (любая клавиша или пэд, одной строкой и двумя
руками), аккорды — тренажёр аккордов и песни по буквам (встроенные, свои текстом, из любой пьесы или MIDI;
фактуры: аккорд целиком, бас + аккорд, Альберти). Строи гитары и баса (готовые, свой по струнам, каподастр,
тюнер по струнам; табы раскладываются под строй) и песни Rocksmith — пользовательские `.psarc` (CDLC, например с
CustomsForge; скачиваешь сам): табы гитары и баса с настоящими ладами и строем, приёмы, части песни, остальные партии
звучат, ноты над табами. Файлы Guitar Pro (.gp3–.gp5, .gp): все партии — гитара и бас табами, фортепиано и мелодии
нотами, барабаны на пэдах, остальные звучат; текстовые табы — «Вставить таб…» с предпросмотром. Упражнения для гитары
и баса табами под свой строй (паучок, пентатоника, гаммы, арпеджио, игра под барабаны), тренажёр грифа и карточки
теории для гитары. Аккорды на гитаре: проверка аккорда по звуку, схемы, тренажёр от открытых до баррэ и сложных,
«минута смен», бой ступенями под барабаны и песни боем. Тренажёр слуха: интервалы, аккорды, ступени в тональности, мелодический и
ритмический диктанты — ответ кнопками или игрой на инструменте, звук заданий — фортепиано или гитара. Бас: грув под
барабаны ступенями, приёмы (i–m, хаммеры, слайды, слэп), формы на грифе, оценка грува (раньше/позже барабанов),
тренажёр «Найди основной тон» и басовые линии к песням по буквам — от основных тонов до walking bass. Джем: аккомпанемент
по кругу (блюз, рок, поп, фанк, баллада или свои аккорды) с подсветкой гаммы и звуков аккорда, уроки импровизации,
«Повтори за мной», запись и разбор соло (ноты, прослушивание, сохранение в MIDI). План гитарных этапов —
[docs/research/guitar-bass.md](docs/research/guitar-bass.md).

## Скачать сборку для Windows

1. Открой вкладку **Actions** репозитория → последний успешный запуск **CI**
   на нужной ветке.
2. Внизу страницы, в разделе **Artifacts**, скачай `MIDI-Teacher-windows-…`.
3. Распакуй архив и запусти `MIDI Teacher_…_x64-setup.exe`. Права
   администратора не нужны: установка идёт в профиль пользователя.

Windows может показать предупреждение SmartScreen: установщик не подписан.
Нажми «Подробнее» → «Выполнить в любом случае».

Если Chrome блокирует архив («Это опасный файл»), скачай сборку без браузера
через GitHub CLI (PowerShell):

```powershell
winget install --id GitHub.cli   # один раз
gh auth login                    # один раз
$id = gh run list -R g1pd78/midi-teacher -b claude/piano-learning-app-mmhm6f -s success -L 1 --json databaseId -q ".[0].databaseId"
gh run download $id -R g1pd78/midi-teacher -p "MIDI-Teacher-windows-*" -D "$env:USERPROFILE\Downloads\MIDI-Teacher"
```

## Локальная разработка (Windows)

Нужно один раз:

1. [Rust](https://rustup.rs) (stable, MSVC) и Visual Studio Build Tools
   с компонентом «Разработка классических приложений на C++».
2. [Node.js 22](https://nodejs.org).
3. LLVM для ASIO: `winget install LLVM.LLVM`, затем
   `setx LIBCLANG_PATH "C:\Program Files\LLVM\bin"` и перезапуск терминала.
   ASIO SDK скачается автоматически при первой сборке.
4. WebView2 уже есть в Windows 10/11.

Дальше:

```bash
npm ci
npm run fetch-soundfont   # SoundFont рояля (~113 МБ), можно пропустить
npm run tauri dev         # приложение с горячей перезагрузкой интерфейса
```

Сборка установщика: `npx tauri build` (результат лежит в `target/release/bundle/nsis/`).

### Только интерфейс в браузере

`npm run dev` и открыть <http://localhost:1420>. Вместо ядра работает
имитация: клавиши компьютера изображают два MIDI-устройства
(`Z S X D C V…` — «Демо-клавиатура», `Q 2 W 3 E R…` — «Демо-пианино»).

## Проверки

```bash
npm run typecheck && npm test          # TypeScript и тесты интерфейса
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace                 # тесты ядра (MIDI, маршруты, синтез, настройки)
```

Сквозной тест «бот играет»: настоящее приложение проходит серию тренажёра,
пьесу, цикл, режим ритма, уровни режима «Разучить», упражнения, запись игры в MIDI и её
открытие как пьесы через имитацию MIDI-входа (Linux: нужны `webkit2gtk-driver` и
`cargo install tauri-driver`):

```bash
npx tauri build --debug --no-bundle
xvfb-run -a node e2e/run.mjs
```

CI (GitHub Actions) запускает всё это на Linux и собирает установщик
для Windows на каждый push.

## Структура

```
crates/mt-core/   ядро на Rust без Tauri: MIDI, маршруты звука, аудио (ASIO/WASAPI), синтезатор,
                  тренажёр, пьесы (ожидание, ритм), движок практики, аппликатура, импорт MIDI
                  (дорожки, руки, выравнивание, MusicXML, запись), гитара и бас (вход звука,
                  тюнер, прослушивание), хранилище (SQLite)
src-tauri/        приложение Tauri: команды, события, настройки
src/              интерфейс на React + TypeScript
scripts/          загрузка SoundFont для сборки, генератор встроенных пьес (gen_pieces.py)
e2e/              сквозной тест через WebDriver (tauri-driver)
docs/             план, архитектура, чеклисты
```

## Лицензии

Встроенный рояль: YDP Grand Piano © Roberto Gordo Saez (проект FreePats),

Встроенные пьесы (`src/pieces/`, генерируются `scripts/gen_pieces.py`, там же источник
каждой мелодии) — общественное достояние: народные песни по записям Musica Viva, нотным
вставкам Википедии и сборнику abc Джона Чемберса; Менуэты BWV Anh. 114 и 115 — по изданиям
Mutopia Project №75 и №76 (Bach-Gesellschaft), «Старинная французская песенка» — по
Mutopia №2080 (Schirmer, 1904); партии левой руки в песнях — простой бас, MIDI Teacher.
