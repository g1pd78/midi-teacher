# Исследование: дневник и планы через Claude, пальцы по камере, подсветка клавиш

## 1. Дневник занятий и планы в JSON/YAML

**Идея.** Приложение ведёт дневник в открытом текстовом формате, его можно отдать Claude и получить в ответ
план занятий, который приложение понимает и показывает в «Занятии на сегодня».

**Цикл:**

1. Приложение само пишет дневник: что играл, сколько минут, точность и темп, трудные такты, пройденные уроки
   курса, свои заметки («болит запястье», «Элиза: т. 5 путаю пальцы»).
2. Кнопка «Попросить план у Claude» копирует в буфер готовый запрос. В нём:
   - дневник за последние 1–4 недели;
   - каталог того, что есть в приложении: id пьес, упражнений, уроков, ступеней тренажёров — чтобы Claude
     ссылался только на существующее;
   - схема файла плана и твоя цель («через месяц сыграть «К Элизе» целиком», «20 минут в день»).
3. Вставляешь запрос в Claude и получаешь YAML плана. Вставляешь его в приложение (или перетаскиваешь файл).
   Приложение проверяет: неизвестные id и ошибки показывает построчно, ничего не ломает.
4. План виден на главной: шаги дня, цели недели, отметки «сделано». Выполнение попадает в дневник, и цикл
   повторяется.

**Формат.** YAML для человека и Claude: читается глазами, в нём можно писать комментарии. Внутри — та же
структура, что JSON, поэтому принимаем оба. К формату — JSON Schema в `docs/` (для проверки и для Claude).
Файлы лежат в `Документы\MIDI Teacher\Дневник\`: по одному на неделю (`2026-W41.yaml`) и `план.yaml`.

Пример дневника (одна запись):

```yaml
date: 2026-10-06
minutes: 34
instrument: piano
items:
  - piece: builtin:fur-elise
    mode: learn            # learn | wait | rhythm
    fragment: "1-4"
    level: 2
    accuracy: 0.91
    tempo: 0.8
    hard_bars: [3, 7]
  - exercise: major-C-parallel
    accuracy: 0.96
    timing_sd_ms: 42
    passed: true
  - course_step: piano-17/3
    done: true
note: "Т. 7 — путаю пальцы в арпеджио левой."
```

Пример плана:

```yaml
title: "К Элизе за 4 недели"
goal: "Сыграть тему «К Элизе» в темпе 100% без ошибок"
daily_minutes: 25
weeks:
  - week: 2026-W41
    focus: "Тема по отрезкам, левая рука отдельно"
    days:
      - day: mon
        steps:
          - exercise: arp-a-parallel2
            target: { tempo: 0.8, accuracy: 0.95 }
          - piece: builtin:fur-elise
            fragment: "1-4"
            level: 1
            hands: left
            minutes: 10
          - ear: ear-interval-2
      - day: wed
        steps: [...]
    check: "К пятнице — такты 1–8 на уровне 3"
```

**Варианты связи с Claude:**

- **Копировать и вставить** (сначала только это). Не нужен ключ, всё под контролем, работает с любым Claude:
  на сайте, в приложении, в Claude Code.
- **Прямо из приложения через Claude API** (позже, по желанию). Свой ключ в настройках, кнопка «Составить план» —
  ответ сразу проверяется и показывается. Плюсы: в один клик. Минусы: нужен ключ и интернет, запросы платные.
- **Claude Code / MCP** (идея): дневник и план — обычные файлы в папке. Claude Code, открытый в этой папке,
  может читать дневник и писать план напрямую.

## 2. Пальцы по камере — насколько тяжело

**Технология.** MediaPipe Hand Landmarker (Google, Apache-2.0 — совместима с нашей GPL-3.0) находит
21 точку каждой кисти по кадру обычной веб-камеры, примерно 30 кадров в секунду на процессоре. Работает прямо
в окне приложения (WebView2 умеет камеру), офлайн. Модель и движок — около 10–15 МБ в установщике.

**Как определить палец.** В момент нажатия клавиши (MIDI) смотрим кадр:
- какой кончик пальца ниже всех;
- какой ближе всего к нажатой клавише — по калибровке: клавиатура на кадре размечается четырьмя
  углами, дальше пересчёт координат.

Сравниваем с аппликатурой и показываем на стане «2 вместо 3».

**Трудности и ожидаемая точность:**
- пальцы закрывают друг друга: подкладывание большого, перекладывание третьего;
- камеру нужно поставить сверху-спереди, при хорошем свете;
- быстрые пассажи: 30 кадров в секунду — это 33 мс между кадрами;
- аккорды.

По опыту похожих проектов на медленной игре и хорошем ракурсе стоит ждать примерно 80–90% верных
определений, на быстрой — меньше. Для обучения этого хватает, если считать результат подсказкой, а не
оценкой: «похоже, здесь был 2-й палец».

**Объём.** Примерно один этап, как «Слух»:
- камера и модель в фоновом потоке;
- мастер калибровки: углы клавиатуры, проверка «нажми до первой октавы большим пальцем»;
- сопоставление пальцев с нотами;
- отметки на стане и статистика.

Для гитары (левая рука на грифе) намного сложнее: гриф под углом, пальцы закрыты. Это отдельный, более
поздний шаг.

## 3. Подсветка «куда жать» прямо на пианино

Наклейки сами светиться не умеют. Работающий и недорогой вариант — **адресная светодиодная лента над
клавишами** (у задней кромки клавиатуры). Так устроены открытые проекты, например
[Piano LED Visualizer](https://github.com/onlaj/Piano-LED-Visualizer) и
[PianoLED Arduino / PianoLux](https://github.com/serifpersia/pianoled-arduino). Есть и готовая плата на
88 светодиодов ([Switch Science](https://www.switch-science.com/collections/all/products/6399)).

**Как это сделать у нас:**
- **Железо** (примерно 1500–3000 ₽):
  - лента WS2812B, 144 светодиода на метр, 1,5–2 м — для 88 клавиш около двух светодиодов на клавишу;
  - плата Raspberry Pi Pico или ESP32-S2/S3: умеет быть USB-MIDI устройством;
  - блок питания 5 В 4–6 А.
- **Прошивка** — в репозиторий (`hardware/led-strip/`). Плата видна в Windows как обычное MIDI-устройство
  «MIDI Teacher Lights»; нота включается — светодиод над клавишей загорается, скорость нажатия задаёт цвет.
- **В приложении:**
  - новое устройство вывода «Подсветка клавиш»;
  - мастер калибровки: нажми самую левую и самую правую клавишу — приложение растягивает ленту по клавишам;
  - в ожидании горят следующие ноты (правая рука — голубым, левая — янтарным, как на экране), в ритме — то, что
    сейчас звучит; пальцы цифрами, увы, не покажешь.
- **Без пайки** — если у пианино есть свои подсвечиваемые клавиши (некоторые Casio и Yamaha) и они
  управляются по MIDI, можно слать ноты подсветки прямо в пианино. Нужно уточнить модель.

**Совсем без электроники:**
- **Полоска-шаблон за клавишами:** приложение печатает на A4 в натуральную ширину клавиш полоску с названиями
  нот, октавами и цветами рук; склеиваешь и ставишь за клавиши.
- **Наклейки на клавиши:** такой же печатный лист с маленькими метками до–ре–ми для первых недель.

## 4. Ещё идеи

- **Педаль как пульт:** левая педаль или дешёвая USB-педаль — «старт/стоп», «заново», «следующий отрезок»;
  руки не отрываются от клавиш.
- **Телефон как камера:** для пальцев можно взять камеру телефона (по Wi-Fi), если нет веб-камеры.
- **Запись видео занятия:** камера плюс нотный стан, чтобы показать учителю или себе.
- **Повторение с интервалами** — оно естественно ложится в план из п. 1: в каталоге для Claude указываем, что и
  когда последний раз игралось.
