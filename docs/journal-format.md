# Дневник и план: форматы файлов

Файлы лежат в папке `Документы\MIDI Teacher\Дневник` (кнопка «Открыть папку дневника» во вкладке
«Дневник»):

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `2026-W41.yaml` | приложение (при каждом открытии вкладки, последние 8 недель) | дневник недели — `midi-teacher/journal@1` |
| `цель.yaml` | приложение (поле «Цель») | `text`, `minutes_per_day` |
| `план.yaml` | ты или Claude (через «Вставить план…» / «Открыть файл…», или прямо в папке) | свои уроки и план по дням — `midi-teacher/plan@1` |

Приложение читает YAML и JSON (JSON — частный случай YAML). Кнопка «Скопировать для Claude» собирает
запрос: цель, дневник за выбранный срок, это описание формата плана и каталог всех заданий для выбранного
инструмента — Claude ссылается только на существующее.

## Дневник: `midi-teacher/journal@1`

```yaml
format: midi-teacher/journal@1
from: 2026-10-05
to: 2026-10-11
goal:                               # если задана во вкладке
  text: Сыграть «К Элизе» к Новому году
  minutes_per_day: 25
days:
  - date: 2026-10-06
    minutes: 34                     # время игры за день
    pieces:                         # отрезки пьес (такты), как в «Разучить» и «Свободно»
      - id: builtin:fur-elise
        title: К Элизе
        fragments:
          - bars: 1-4
            level: 2                # уровень «Разучить» (0 Знакомство … 4 По памяти); нет — свободная игра
            attempts: 3
            best_accuracy: 0.91
            tempo: 0.8              # доля от темпа пьесы
            hard_bars: [3, 7]       # такты с ошибками
    exercises:                      # упражнения, тренажёры, шаги курса — всё, что пишет результат
      - id: major-C-parallel
        title: "Упражнение: Гамма до мажор: обе руки"
        attempts: 2
        best_accuracy: 0.96
        tempo: 1
        passed: true                # «Засчитано»
    note_trainer:                   # тренажёр нот: ступени
      - level: 3
        series: 2
        best_accuracy: 0.9
        passed: true
```

## Свои уроки и план: `midi-teacher/plan@1`

```yaml
format: midi-teacher/plan@1
title: "К Элизе за 4 недели"
goal: "Тема «К Элизе» в темпе без ошибок"   # необязательно
instrument: piano                           # piano | guitar | bass | drums (по умолчанию piano)
lessons:                                    # свои уроки — как уроки курса
  - id: elise-1                             # латиница, цифры, дефис; уникальный
    title: "Левая рука и арпеджио"
    goal: "Арпеджио ля минор, левая рука темы"
    steps:
      - theory: staff
      - exercise: arp-a-parallel2
        target: { tempo: 0.8, accuracy: 0.95 }   # необязательно: цель — показывается у шага
        note: "Медленно, следить за 4-м пальцем" # необязательно
      - piece: fur-elise
        hands: left                              # right | left | both
plan:                                       # по дням
  - date: 2026-10-07                        # ГГГГ-ММ-ДД
    lesson: elise-1                         # свой урок (или список)
  - date: 2026-10-08
    course: piano-17                        # урок курса приложения (или список)
    steps:                                  # и/или отдельные шаги
      - ear: interval-2
    note: "Короткий день — 15 минут"
```

### Шаги

| Запись | Что это |
|---|---|
| `theory: <id>` | карточка теории («Понятно» — шаг сделан) |
| `notes: <1–9>` | ступень тренажёра нот (фортепиано) |
| `exercise: <id>` | упражнение для фортепиано |
| `guitar: <id>` | упражнение или пьеса для гитары / баса (`gtr-…`, `bass-…`) |
| `drum: <id>` | грув или рудимент (`groove-rock`, `rud-paradiddle`) |
| `drum_song: <id>` | песня на барабанах (`ode`, `birthday`…) |
| `read: <n>` | ступень чтения с листа |
| `rhythm: <id>` | ступень ритма (`line-3`, `hands-1`…) |
| `chords: <n>` / `guitar_chords: <n>` | тренажёр аккордов (фортепиано / гитара) |
| `fret: <n>` | тренажёр грифа |
| `ear: <id>` | слух (`interval-2`, `chord-1`, `degree-1`, `melody-1`, `rhythm-1`…) |
| `root: <n>` | «Найди основной тон» (бас) |
| `echo: <n>` / `jam: <n>` | «Повтори за мной» / урок импровизации |
| `piece: <id>` (+ `hands`) | встроенная пьеса (`fur-elise`, `ode-to-joy`…) — в режиме ожидания |
| `song: <id>` (+ `style` / `strum` / `bass`) | песня по буквам: фактура для фортепиано, бой для гитары, басовая линия |

Полный список id для инструмента — в каталоге внутри запроса «Скопировать для Claude». Шаг засчитывается
по правилам приложения (упражнение — «Засчитано», пьеса — сыграна почти без ошибок, теория — прочитана);
в дне плана шаг отмечается, если сыгран сегодня. Ошибки в файле приложение показывает с местом
(`lessons[1].steps[2]: нет такого задания…`) и такой план не загружает.

## Повторение с интервалами

Не хранится отдельно — считается по истории попыток. Выученное (упражнение после «Засчитано», отрезок пьесы
на уровне «В темпе» или «По памяти» с точностью от 90%, пройденный урок курса) возвращается через 1, 3, 7, 14 и
30 дней. Повторение в срок или позже: удачно — следующий интервал, неудачно — снова через день. Игра до срока
не мешает и не считается.
