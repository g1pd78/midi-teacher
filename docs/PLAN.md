# MIDI Teacher — план продукта (функционал, визуал, тестирование)

Техническая архитектура (модель данных, движок оценки, бюджет задержки) описана в [ARCHITECTURE.md](ARCHITECTURE.md).

## Контекст

Пользователь учится играть на фортепиано **с нуля** (ноты не читает). Оборудование:
**Windows**, цифровое пианино со звуком (**USB-MIDI**, вход и выход), MIDI-клавиатура
без звука. Играть будет на обоих инструментах, по ситуации.

Цель: десктопное приложение, где выбираешь трек (MusicXML/MIDI) и играешь его
по **интерактивному нотному стану**. Трек повторяется много раз, подсказки
постепенно убираются, пока пьеса не играется по памяти. Плюс тренажёры для
новичка: чтение нот, гаммы и упражнения, теория по ходу.

Архитектура уже выбрана ([ARCHITECTURE.md](ARCHITECTURE.md)): **Tauri 2 — ядро на Rust** (MIDI, звук,
время, оценка) **+ интерфейс на React/TypeScript** (Verovio для нот, Canvas для
падающих нот). Этот план фиксирует функционал, визуал, порядок этапов и тестирование.

Решения пользователя (из опроса):
| Тема | Решение |
|---|---|
| Уровень | С нуля: названия нот, подсветка клавиш, обучение чтению нот |
| Экран игры | Нотный стан сверху + падающие ноты и клавиатура снизу (падающие скрываемы) |
| Дополнительно | Тренажёр чтения нот, гаммы/упражнения, базовая теория по ходу |
| Названия нот | Переключатель (по умолчанию До-Ре-Ми, можно C-D-E) |
| Стиль | Тёмная спокойная тема, ноты на светлой «бумаге» |
| Мотивация | Спокойная статистика (без очков и звёзд) |
| Сборки | Готовый .exe из GitHub Actions + инструкция для локальной разработки |
| Приёмка | После каждого этапа: сборка + чеклист, проверка на реальных инструментах |
| Порядок | Каркас → тренажёр чтения нот → пьесы |
| Библиотека | Папка на диске + перетаскивание файла в окно (копируется в папку) |
| Уровни подсказок | Приложение предлагает перейти, решает пользователь |
| Вторая рука | Приложение играет её (можно выключить) |
| Встроенный звук | Качественный SoundFont рояля (~150+ МБ) |
| Контент | Встроенная библиотека 10–15 простых пьес из общественного достояния |

## 1. Звук и устройства (с учётом Windows + двух инструментов)

**Все MIDI-входы подключаются автоматически и одновременно**: играешь на том,
что под рукой. Горячее переподключение: список портов опрашивается раз в секунду.

**Маршрут звука настраивается для каждого входа:**
- Цифровое пианино → «звучит само» (задержка 0, приложение только слушает).
- MIDI-клавиатура → **через цифровое пианино (MIDI Out по USB)**: по умолчанию, если
  пианино подключено. Задержка ~1–3 мс, звук настоящего пианино.
- Запасной вариант (пианино выключено) → встроенный синтезатор: `rustysynth` +
  SoundFont рояля, вывод через `cpal`.

**Аудиовывод: ASIO с первого этапа.**
- `cpal` собирается с feature `asio`. В настройках выбор бэкенда: **ASIO**
  (список ASIO-драйверов + размер буфера) или **WASAPI**.
- По умолчанию: ASIO, если в системе есть ASIO-драйвер; иначе WASAPI, и мастер
  предлагает поставить бесплатный универсальный драйвер (FlexASIO или ASIO4ALL)
  со ссылкой и коротким пояснением.
- Цель с ASIO: буфер 64–128 сэмплов, задержка синтезатора ~3–6 мс.
- Если ASIO-драйвер занят или упал, приложение автоматически переключается
  на WASAPI и показывает уведомление (звук не пропадает).
- Сборка: CI (windows-latest) использует LLVM/clang для bindgen; ASIO SDK
  скачивается скриптом сборки `asio-sys` (или по `CPAL_ASIO_DIR`). Для
  локальной сборки README описывает установку LLVM.

**Партия второй руки и метроном** звучат там же, где выбран «звук приложения»:
через MIDI Out на пианино (отдельный канал, чтобы не обрывать ноты ученика)
или во встроенном синтезаторе.

**SoundFont** (~150 МБ, свободная лицензия с правом распространения, например
Salamander Grand Piano / YDP Grand, CC BY) в git не хранится: CI скачивает его
по закреплённой ссылке с проверкой SHA-256 и кладёт в ресурсы установщика.
Загружается в фоне при старте; пока грузится, играет простой встроенный синтез.
Можно подключить свой `.sf2`.

**Мастер первого запуска (3 шага):**
1. «Нажми клавишу на цифровом пианино» → определяем устройство, у которого есть выход.
2. «Нажми клавишу на MIDI-клавиатуре» → назначаем ей звук через пианино, проверяем: «Слышно?»
3. «Нажми самую левую и самую правую клавиши» → запоминаем диапазон каждой
   клавиатуры. Если пьеса выходит за диапазон, предупреждаем и предлагаем
   сдвиг на октаву.

## 2. Функционал по разделам

### Главный экран
«Продолжить» (последняя пьеса и фрагмент), разделы:
**Пьесы · Тренажёр нот · Упражнения · Справочник · Прогресс · Настройки**.

### Тренажёр чтения нот (первый учебный модуль)
- На стане показывается нота, нужно нажать нужную клавишу (октава учитывается).
- Ступени: скрипичный ключ до1–соль1 → до1–до2 → басовый ключ → оба ключа →
  добавочные линейки → знаки альтерации. Следующая ступень открывается при
  точности от 90% и среднем времени реакции меньше 2 с.
- Адаптивный подбор: ноты с ошибками и медленной реакцией выпадают чаще.
- Подсказки для новичка (отключаемые): название ноты и подсветка клавиши после
  двух ошибок на ноте или 3 секунд раздумья (3, а не 2, чтобы подсказка не
  совпадала с порогом прохождения ступени).
- Подача: «по одной» (крупная нота) или «лентой» (8 нот, текущая подсвечена,
  после восьмёрки — следующая). При ошибке: «ждать правильную» или «идти дальше».
  Серия — 20 нот, октава учитывается строго.
- Статистика по каждой ноте: точность и время реакции.

### Пьесы: интерактивный стан (ядро)
- Библиотека: встроенные пьесы + пользовательская папка (`Документы\MIDI Teacher`),
  перетаскивание `.musicxml/.mxl/.mid` в окно копирует файл в эту папку.
  На карточке: сложность и прогресс (полоска фрагментов по уровням).
- **Экран игры**: сверху нотный стан (Verovio, SVG на светлой «бумаге») с курсором;
  снизу падающие ноты и клавиатура (диапазон по пьесе); верхняя панель: рука
  (П / Л / обе), режим, темп 30–120%, цикл по тактам, метроном, уровень подсказок.
- Подсказки: аппликатура (если есть в файле), названия нот (переключатель),
  подсветка следующих клавиш, цвет по рукам.
- **Режим ожидания**: курсор ждёт, пока нажат весь аккорд (разброс ~150 мс,
  ноты под лигой не требуются). Ошибка подсвечивается красным, но курсор не двигается.
- **Режим ритма**: музыка идёт в темпе; окна допуска ±50 мс «точно», ±120 мс
  «нормально»; пропуски и лишние ноты считаются ошибками.
- Вторая рука играется приложением и подстраивается под продвижение ученика.
- Педаль (CC64) учитывается.
- **Итог попытки**: точность, ритм (раньше/позже), трудные такты; предложение
  сменить уровень подсказок.

### Движок практики (как выучить пьесу наизусть)
- Автоматическая разбивка на фрагменты по 2–4 такта (с учётом двойных тактовых
  черт и репетиционных знаков); границы можно подправить.
- Уровни для каждого фрагмента: 0 Знакомство (слушаем) → 1 Полные подсказки
  (руки отдельно, ожидание) → 2 Ноты с курсором (руки вместе) → 3 Только ноты,
  ритм 60→100% → 4 По памяти (ноты фрагмента скрыты).
- После 3 проходов подряд с точностью ≥95% приложение **предлагает** перейти
  дальше. При повторных неудачах предлагает вернуться. Уровень всегда можно
  поменять вручную.
- Сцепление фрагментов: 1 → 2 → 1+2 → 3 → 1–3 → …
- Повторение с интервалами — отложено (см. «Бэклог»): что и когда повторять, решает ученик.

### Упражнения
Генерируются кодом, а не из файлов, со стандартной аппликатурой:
- пять пальцев — позиции «до», «соль», «фа», «ре»: вверх-вниз, терции, узоры;
- мажорные гаммы до 3 знаков (до, соль, ре, ля, фа, си♭, ми♭): 1 октава каждой рукой →
  расходящиеся от одной ноты → параллельно в октаву → 2 октавы;
- минорные гаммы (гармонический и мелодический) и арпеджио трезвучий;
- упражнения в духе Ганона (узоры по белым клавишам вверх и вниз).

Упражнения выстроены **ступенями**: следующее открывается, когда пройдено предыдущее
(точность от 95% и ровный ритм в заданном темпе). **Разминка дня** — подборка на ~5 минут
из открытых упражнений. Оценка: верные ноты, **ровность ритма** (отклонения по нотам,
где сбиваешься — например, на подкладывании пальца) и **ровность громкости** по силе
нажатия (какие пальцы звучат слабее; сравнение только внутри попытки). Играются на том же
экране, что и пьесы (ноты, падающие ноты, клавиатура, метроном).

### Теория по ходу и справочник
- ~25 коротких карточек: длительности, паузы, точка, лига, знаки альтерации,
  ключи, размер, динамика, педаль и т. д.
- Когда элемент **впервые** встречается в пьесе, упражнении или тренажёре, сбоку
  появляется короткая плашка («Новое: …»), игра не останавливается; «Подробнее»
  открывает карточку. Все карточки — в разделе «Справочник».

### Главный экран: «Занятие на сегодня»
Три шага по порядку: разминка дня → серия тренажёра нот → «Продолжить» последнюю пьесу
с того же отрезка. Отметки, что уже сделано сегодня. Без очков.

### Прогресс
Минуты практики по дням, точность по пьесам, освоенные ноты в тренажёре,
тепловая карта трудных тактов на стане. Без очков и звёзд.

### Встроенная библиотека (общественное достояние)
Кодируем в MusicXML сами (`scripts/gen_pieces.py`), по возрастанию сложности, упор на простое.
Мелодии — только по проверенным записям (Mutopia Project, Musica Viva, нотные вставки
Википедии, сборники abc), источник указан у каждой пьесы. Сейчас 11:
«Ах, скажу я вам, мама», «Братец Яков», «При свете луны», «Ода к радости», «Во поле
берёза стояла», «Бубенчики» (припев), «Калинка» (припев), Брамс «Колыбельная», Чайковский
«Старинная французская песенка» (упрощённо), Менуэты соль мажор и соль минор.
«Ах вы, сени», «В саду ли, в огороде» и Бетховен «Сурок» — в бэклоге: не нашлось
надёжной открытой записи мелодии (по памяти не кодируем).

### Импорт MIDI
- MIDI-файлы из папки библиотеки открываются как пьесы. При первом открытии — **окно дорожек**:
  у каждой инструмент, число нот, диапазон, прослушивание; роль — правая рука, левая,
  обе (разделить по высоте), аккомпанемент (звучит, в нотах не показывается) или выключить.
  Приложение предлагает раскладку само, выбор запоминается.
- **Руки** для дорожки «обе» делятся умным алгоритмом по высоте (следит за положением рук,
  аккорды шире децимы делит); неверную руку у ноты можно поправить в режиме «Руки…».
- **Нотный стан**: ноты выравниваются по сетке (шестнадцатые или триоли — по каждой доле),
  размер и тональность — из файла или определяются; темп — из начала файла. Дальше работает
  всё: «Разучить», аппликатура, теория, прогресс.
- **Сохранить как MusicXML** — импортированные ноты файлом (для MuseScore).
- **Запись своей игры в MIDI** с метрономом и отсчётом: файл ложится в библиотеку.
- **Транспонирование** любой пьесы на полутона (−12…+12), запоминается для пьесы.

## 3. Визуал

- **Тёмная спокойная тема**: фон `#15171C`, панели `#1E2128`, текст `#E6E6E6`.
  Нотный стан на светлой «бумаге» `#F3EEE4` со скруглением и мягкой тенью.
- **Цвета рук**: правая — голубой `#5AA9FF`, левая — янтарный `#FFB454`
  (падающие ноты, клавиши, подсветка на стане).
- **Обратная связь**: верно — зелёный `#4CC38A` (короткая вспышка), ошибка —
  красный `#FF5C5C`, неточный ритм — жёлтый. Никаких громких эффектов.
- **Разметка экрана игры**: панель 56 px · стан ~45% · падающие ноты ~35% ·
  клавиатура ~20%. Всё масштабируется от 1366×768 до 4K. Падающие ноты скрываются
  одной клавишей, тогда стан растягивается.
- Шрифт интерфейса Inter; ноты рисуются шрифтом Verovio (Leipzig/Bravura).
- Горячие клавиши: Пробел — старт/пауза, R — заново, ←/→ — фрагмент,
  1/2/3 — рука, H — скрыть падающие ноты, +/− — темп.
- Русский интерфейс.

## 4. Технический стек (коротко)

- **Rust-ядро** (`crates/mt-core`, без зависимости от Tauri): `midir` (MIDI),
  `cpal` (ASIO + WASAPI; feature `asio` включается только для Windows), `rustysynth` (SoundFont), `midly` (MIDI-файлы), `rusqlite`
  (прогресс), `crossbeam-channel`. Модули: `devices`, `audio`, `synth`, `score`,
  `engine` (transport, judge), `practice`, `trainer`, `exercises`.
- **Приложение** (`src-tauri`): команды и события Tauri, настройки (JSON), плагин диалогов.
- **Интерфейс** (`src`): React 19 + TypeScript + Vite, Zustand; Verovio (WASM)
  в Web Worker; падающие ноты на Canvas 2D (PixiJS, если не хватит производительности).
- Время и оценка живут только в Rust. Интерфейс интерполирует позицию.

## 5. Этапы (после каждого: .exe из CI + чеклист для проверки)

| # | Этап | Результат для пользователя |
|---|---|---|
| 0 | **Каркас** | Оба инструмента подхватываются сами; MIDI-клавиатура звучит через пианино; встроенный рояль как запасной, с выводом через **ASIO** (или WASAPI); экранная клавиатура показывает нажатия; мастер первого запуска; настройки сохраняются; CI собирает установщик с поддержкой ASIO |
| 1 | **Тренажёр чтения нот** | Можно начинать учить ноты; заодно проверены Verovio и оценка нажатий |
| 2 | **Интерактивный стан** | Библиотека (папка + перетаскивание), 2 встроенные пьесы (Ода к радости, Менуэт соль мажор), режим ожидания, руки отдельно, вторая рука от приложения, аппликатура и названия нот, вид «строка» / «страницы» |
| 3 | **Падающие ноты и ритм** | Падающие ноты синхронно со станом (в ожидании замирают вместе с курсором), темп 30–120%, цикл по тактам (клик по стану или поля), отсчёт и метроном — отдельные переключатели, режим ритма (музыка не ждёт, оценка ±50/120/200 мс), итог попытки |
| 4 | **Движок практики** | Ведущий режим «Разучить» (свободная игра остаётся), фрагменты по 2–4 такта с правкой границ, уровни подсказок 0–4 с предложением перехода, «По памяти» скрывает ноты отрезка и падающие ноты, сцепление, экран «Прогресс» (минуты по дням, уровни фрагментов, тренажёр нот, тепловая карта трудных тактов) |
| 4а | **Аппликатура** | Палец у каждой ноты: из файла → ручная правка (клик по ноте, 1–5, хранится для пьесы) → автоматический подбор (минимум «стоимости» движений руки: растяжка, подкладывание, чёрные клавиши, аккорды). Показ: цифра над нотой, в падающей ноте и на подсвеченной клавише; подобранные автоматически — серым |
| 5 | **Упражнения, теория, библиотека** | Упражнения ступенями (пять пальцев, мажорные и минорные гаммы, арпеджио, Ганон) с оценкой ровности ритма и громкости, разминка дня, «Занятие на сегодня» на главной, плашки теории и «Справочник», встроенная библиотека до 10–15 простых пьес |

## 6. Тестирование

**Автотесты (запускаются в CI на каждый push):**
- Rust unit-тесты на чистой логике: разбор MIDI (включая фильтр Active Sensing,
  NoteOn с силой 0), маршрутизация, judge (ожидание и ритм) на синтетических
  потоках нажатий, машина состояний уровней подсказок, подбор аппликатуры,
  генерация гамм и аппликатуры, адаптивный выбор нот в тренажёре, импорт и
  квантизация MIDI.
- Тесты интерфейса (Vitest): Verovio в Node загружает каждую встроенную пьесу;
  проверяются число нот, распределение по рукам, монотонность временной карты;
  чистые функции (геометрия падающих нот, названия нот, раскладка клавиатуры).
- **Виртуальное MIDI-устройство**: команда разработчика `simulate_midi` и режим
  «бот играет пьесу» с заданным процентом ошибок. Сквозной тест: приложение играет
  само и выдаёт ожидаемую точность (tauri-driver + WebdriverIO под xvfb в Linux CI).
- Линтеры: `cargo fmt --check`, `clippy -D warnings`, `tsc --noEmit`.

**CI (GitHub Actions):**
- `test` (Ubuntu): линтеры, Rust-тесты, Vitest, сквозные тесты.
- `build-windows` (windows-latest): LLVM для ASIO, скачивание SoundFont
  по SHA-256, `tauri build`, NSIS-установщик как артефакт каждого push.

**Ручная приёмка** (`docs/checklists/stage-N.md`): короткий сценарий «сделай →
должно произойти» на реальном пианино и клавиатуре. Замечания присылаешь в чат,
исправляю, повторная проверка.

**Диагностика в приложении:** экран «Устройства и звук»: активные входы/выходы,
последние MIDI-сообщения, фактический размер аудиобуфера и оценка задержки
вывода, счётчик кадров (в режиме разработчика).

## Бэклог

Отложено по решению пользователя или как идеи на будущее:

- **Повторение с интервалами**: выученные фрагменты возвращаются через 1, 3, 7, 14 дней
  (сейчас повторение — на усмотрение ученика).
- **Распознавание пальцев по камере** (например, MediaPipe Hands): проверять, каким пальцем
  нажата клавиша — MIDI этого не передаёт.
- **Схема ладоней** с подсвеченным пальцем (вариант показа аппликатуры, не выбран для этапа 4а).
- **Ещё пьесы**: «Ах вы, сени», «В саду ли, в огороде», Бетховен «Сурок» — когда найдётся
  надёжная открытая запись мелодии (или пришлёшь ноты).

## 7. Риски

| Риск | Решение |
|---|---|
| WinMM открывает порт только для одного приложения (пианино занято другой программой) | Понятное сообщение «устройство занято: закройте X»; позже Windows MIDI Services (Win 11) |
| Ноты второй руки через MIDI Out обрывают ноты ученика на той же клавише | Второй канал MIDI для приложения; настройка канала |
| ASIO-драйвер обычно эксклюзивный (пока приложение открыто, другие программы могут остаться без звука) | Переключатель ASIO/WASAPI в настройках; поясняем в мастере; освобождаем драйвер, когда звук приложения не нужен (всё звучит через пианино) |
| Нет ASIO-драйвера у звуковой карты | Мастер предлагает FlexASIO/ASIO4ALL; до установки — WASAPI с минимальным буфером |
| Сборка с ASIO SDK (bindgen, лицензия SDK) | LLVM в CI; SDK подтягивается при сборке и не хранится в репозитории |
| Пьеса шире 49/61 клавиш MIDI-клавиатуры | Калибровка диапазона в мастере, предупреждение, сдвиг на октаву |
| Большой SoundFont увеличивает установщик и время загрузки | Загрузка в фоне, простой синтез до готовности; ссылка с SHA-256 |
