# Чеклист этапа 0: каркас

Проверяется на Windows с цифровым пианино (USB) и MIDI-клавиатурой.
Для каждого пункта: ✅ работает / ❌ не работает + что произошло.
Если что-то не так, пришли в чат номер пункта и описание.
Лог приложения лежит в `%LOCALAPPDATA%\com.g1pd78.miditeacher\logs\`.

## Установка

1. Скачай установщик из Actions (см. README), установи, запусти.
   → Открывается окно «Подключим инструменты» с клавиатурой внизу.

## Мастер первого запуска

2. Оба инструмента подключены по USB до запуска.
   → Под заголовком «Подключено: …» видны оба устройства.
3. Нажми клавишу на **цифровом пианино**.
   → Пианино звучит само; мастер пишет «Пианино: …, звучит само, через него же будет звучать клавиатура».
   (Если написано «выход не найден», сообщи точные имена устройств из раздела «Устройства и звук».)
4. Нажми клавишу на **MIDI-клавиатуре**.
   → Шаг «Проверим звук». Играя на MIDI-клавиатуре, слышишь звук **из цифрового пианино**.
5. Ответь «Да, слышно».
   → Шаг «Размер клавиатуры»: нажми самую левую и самую правую клавиши MIDI-клавиатуры, затем пианино.
6. → «Готово» со сводкой. Количество клавиш совпадает с реальным (например, 49/61 и 88).
7. Нажми «Начать».
   → Главный экран.

## Главный экран

8. Нажми клавишу на любом инструменте.
   → Большая надпись с названием ноты (например, «До первой октавы»), сила нажатия, имя устройства.
   Клавиша подсвечивается на экранной клавиатуре цветом устройства.
9. Возьми аккорд из 3–4 нот.
   → Все клавиши подсвечены, под названием чипы нот аккорда.
10. Нажми правую педаль пианино.
    → Рядом с названием ноты появляется «педаль».
11. Нажми клавишу мышью на экранной клавиатуре.
    → Звук идёт из цифрового пианино, клавиша подсвечивается зелёным.
12. Задержка на MIDI-клавиатуре (звук через пианино) субъективно не ощущается.

## Устройства и звук

13. Открой «Устройства и звук».
    → Оба входа «подключено»; у пианино «Звучит само», у клавиатуры «Через <пианино>».
14. Выдерни USB MIDI-клавиатуры, подожди 2 секунды.
    → Статус «не подключено». Вставь обратно: через 1–2 секунды «подключено», клавиши снова работают.
15. У MIDI-клавиатуры поставь «Встроенный синтезатор».
    → Звук идёт из колонок/наушников компьютера. В блоке «Встроенный синтезатор»:
    состояние «работает», вывод ASIO или WASAPI, задержка вывода.
    Запиши, какой вывод и какая задержка показаны.
16. «Звук рояля» — должен быть «SoundFont: YDP-GrandPiano.sf2» (звучит как рояль).
    Если там «Встроенный простой синтез», сообщи: значит, SoundFont не попал в сборку.
17. Если ASIO-драйвера нет: появляется подсказка про FlexASIO. Установи FlexASIO, перезапусти приложение.
    → Вывод «ASIO», задержка меньше, чем была с WASAPI. Запиши обе цифры.
18. Поменяй размер буфера на 64, затем на 256.
    → Звук не пропадает; «Буфер» и «Задержка вывода» меняются. На 64 нет треска
    (если трещит, счётчик «Прерывания звука» растёт — сообщи цифры).
19. Верни MIDI-клавиатуре «Через <пианино>».
    → Состояние синтезатора «отдыхает» (аудиоустройство освобождено).
20. MIDI-монитор показывает нажатия, отпускания и педаль с интервалами в мс.
21. Переключи «Названия нот» на C-D-E.
    → На главном экране и клавиатуре названия вида C4.
22. Закрой и снова открой приложение.
    → Мастер не показывается, настройки маршрутов и названий нот сохранились.

## Сбои

23. Открой другую программу, которая использует MIDI-вход пианино (если есть), и запусти приложение.
    → Понятное сообщение «не удалось открыть… занято другой программой», приложение не падает.
