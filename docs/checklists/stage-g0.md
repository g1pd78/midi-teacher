# Чеклист этапа Г0: гитара и бас — вход звука, прослушивание, тюнер

Проверяется на Windows с Rocksmith Real Tone Cable (или звуковой картой с инструментальным входом),
электрогитарой и бас-гитарой. Для каждого пункта: ✅ работает / ❌ не работает + что произошло.
Запиши цифры, где просят: по ним настрою следующие этапы.

## Подключение

1. В шапке вкладка «Гитара». Вверху переключатель «Гитара / Бас».
2. Подключи Real Tone Cable к USB, гитару — к кабелю. «Обновить» → в списке «Вход» появилось
   устройство вроде «Rocksmith Guitar Adapter …». **Запиши точное имя.**
3. Выбери его, включи «Слушать вход» → строка «… · 48 кГц · буфер N (… мс)». **Запиши буфер.**
4. Играешь — полоска уровня двигается (громко — жёлтая). Ползунок «Усиление» меняет уровень.
   Если выкрутить усиление и сильно ударить по струнам — предупреждение «Слишком громко».

## Слышать себя

5. «Звук гитары в колонках/наушниках» → слышишь гитару через компьютер. «Громкость» работает.
6. «Лёгкий перегруз» заметно отличается от «Чистый» (для гитары приятнее, для баса — по вкусу).
7. Под переключателями «Задержка прослушивания ≈ N мс». **Запиши N** и субъективно: мешает или нет.
8. Быстрый путь (если задержка заметна): «Настройки → Устройства и звук» → вывод **ASIO**
   (FlexASIO или ASIO4ALL; в ASIO4ALL включи в его окне вход кабеля). Вернись во вкладку «Гитара»,
   выбери вход «ASIO — входы драйвера вывода». → Звук есть, задержка 5–10 мс. **Запиши цифры** или что не так.
9. Включи пьесу в режиме «Ритм» с метрономом и останови — гитару по-прежнему слышно.

## Тюнер

10. Сыграй открытые струны гитары: тюнер показывает Ми 2, Ля 2, Ре 3, Соль 3, Си 3, Ми 4.
    Стрелка стоит спокойно, в зелёной зоне — «в строю ✓» у нужной струны.
11. Под струной подсказка «выше» / «ниже»: крутишь колок в эту сторону — стрелка идёт к нулю.
12. Сверь с другим тюнером (например, в телефоне): после настройки разница не больше 3 центов.
13. «Бас»: четыре струны Ми 1, Ля 1, Ре 2, Соль 2. **Низкая ми определяется как Ми 1** (а не на
    октаву выше), стрелка не скачет.
14. Флажолет или взятый аккорд тюнер может показывать неуверенно — это нормально, главное —
    открытые струны.

## Калибровка задержки

15. «Калибровка задержки» → «▶ Начать»: 8 щелчков. На каждый бей по заглушённым струнам.
    → «Задержка входа N мс, разброс ±M мс (попаданий 8 из 8)». «Сохранить» → «Сейчас: N мс».
16. Повтори 2–3 раза: значения близки (±10 мс). **Запиши N и M.**

## Запись для проверки

17. «● Записать 20 с»: сыграй открытые струны по очереди, гамму, любой рифф. → «Сохранено:
    …\Документы\MIDI Teacher\Гитара\Гитара ДД.ММ …wav». «Открыть папку» показывает папку.
18. То же для баса (переключи «Бас»).
19. **Пришли мне оба WAV-файла** (прикрепи к сообщению). По ним настрою распознавание нот (Г1).

## Прочее

20. Перезапусти приложение — вход, усиление, тембр, инструмент и сохранённая задержка на месте.
21. Выдерни кабель при включённом входе → сообщение об ошибке, приложение не падает. Вставь,
    «Обновить», выбери вход снова → работает.
22. Пианино и MIDI-клавиатура работают как раньше (ноты, звук, пьесы).
