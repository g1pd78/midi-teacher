# Чеклист этапа 7: доводка

Проверяется на Windows на свежей сборке из Actions.
Для каждого пункта: ✅ работает / ❌ не работает + что произошло.

## Версия сборки

7-1. «Настройки» → внизу «О программе»: «Сборка» — 7 символов (например, `a1b2c3d`) и дата сборки.
7-2. «Открыть страницу сборок» → в браузере открывается список запусков CI на нашей ветке.
     У верхнего зелёного запуска номер коммита начинается с тех же символов, что в «Сборке»,
     если у тебя последняя версия. Если символы другие — вышла новая сборка.

## Панель пьесы

7-3. Открой любую пьесу на окне 1366 px: верхняя панель помещается в одну строку
     (← Пьесы, название, инструмент, «Разучить/Свободно», руки, режим, «Заново», ●, «⋯»).
7-4. «⋯» → панель с «Строка / Страницы» и «Тон − 0 +». У MIDI-пьес там же «Дорожки…»,
     «Руки…», «Сохранить MusicXML…».
7-5. «Страницы» из меню переключают вид, как раньше. «Тон +1» транспонирует.
7-6. Esc при открытом меню закрывает только меню (пьеса остаётся). Клик мимо — тоже закрывает.
7-7. Под нотами строки переключателей стали короче: «Тон» и кнопок MIDI там больше нет.

## Горячие клавиши

7-8. «?» в правом конце шапки или клавиша `?` (Shift+/) / F1 на любом экране → окно
     «Горячие клавиши» по разделам: везде, пьеса, «Пальцы…», студия.
7-9. Пока окно открыто, Пробел не запускает пьесу. Esc, `?`, F1, «Понятно» или клик мимо закрывают
     окно, пьеса остаётся открытой.
7-10. В поле ввода (например, «Такты с … по …») `?` печатается как обычно, окно не открывается.

## Резервная копия

7-11. «Настройки» → «Резервная копия» → «Сохранить копию…» → диалог «Сохранить как», имя
      `MIDI Teacher <дата>.mtbackup` → «Сохранено: <путь> (прогресс есть, треков студии: N)».
7-12. Поиграй что-нибудь (например, серия тренажёра), чтобы прогресс изменился.
7-13. «Восстановить…» → вопрос «Восстановить из резервной копии?» → ОК → выбери файл из 7-11 →
      «Копия от <дата> готова к восстановлению… Настройки и прогресс заменятся после перезапуска»
      и кнопка «Перезапустить сейчас».
7-14. «Перезапустить сейчас» → приложение закрывается и открывается снова; в «Прогрессе» —
      состояние на момент копии (серии из 7-12 нет), настройки устройств и звука как были.
7-15. Треки студии из копии на месте сразу, даже без перезапуска (одноимённые заменены).
7-16. «Восстановить…» с посторонним файлом (например, .mid) → понятная ошибка
      «Не восстановлено: это не резервная копия MIDI Teacher», ничего не меняется (тип файла в диалоге —
      «Все файлы»).
7-17. (По желанию) Перенос на второй компьютер: установить, «Восстановить…», перезапуск —
      прогресс и треки на месте. Свои ноты и записи переносятся копированием папки
      `Документы\MIDI Teacher`.

## Прочее

7-18. Пьесы, упражнения, барабаны, гитара, студия работают как раньше.
