# Чеклист этапа 4: движок практики и экран «Прогресс»

Проверяется на Windows с цифровым пианино / MIDI-клавиатурой. Для каждого пункта:
✅ работает / ❌ не работает + что произошло.

## Режим «Разучить»

1. Открой «Оду к радости». Вверху включён «Разучить» (рядом «Свободно»). Под панелью —
   строка «Отрезки»: `1 · 2 · 1+2 · 3 · 1–3 · 4 · 1–4`, у каждого точки уровня.
   Выделен отрезок `1`, на нотах подсвечены такты 1–4.
2. «Менуэт соль мажор» делится на 8 фрагментов по 4 такта.
3. Клик по такту на нотах выбирает фрагмент, в котором этот такт. Клавиши ← / →
   переключают соседний отрезок.
4. «Свободно» возвращает прежний экран (руки, режим, темп, цикл, переключатели),
   «Разучить» — ведущий режим. Выбор запоминается.

## Уровни

5. **0 Слушать.** Кнопка «▶ Слушать» (или пробел): приложение играет обе руки отрезка
   по кругу, клавиши и ноты подсвечиваются. После первого круга появляется
   предложение «Попробуешь сыграть сам?» → «Перейти» ставит уровень 1.
6. **1 Подсказки.** Режим ожидания, под нотами названия, клавиши подсвечены, падают ноты.
   Сначала правая рука (левую играет приложение). После каждого круга сообщение
   «Проход засчитан (100%) · серия N из 3» или «X% — серия сначала».
7. После 3 чистых проходов правой рука меняется на левую; после 3 чистых левой —
   предложение «Перейти на уровень 2 «Ноты с курсором»?». «Ещё потренируюсь» убирает
   его (Esc), «Перейти» (Enter) меняет уровень.
8. **2 Ноты.** Обе руки, названий нот нет, подсветка и падающие ноты остаются.
9. **3 В темпе.** Режим ритма: «▶ Старт», отсчёт/метроном по переключателям. Нет падающих
   нот и подсветки. Темп начинается с 60% и после каждого хорошего круга растёт на 10%
   (сообщение «темп 70%»), игра сама продолжается в новом темпе. Предложение перейти
   дальше — после 3 хороших кругов в 100%.
10. **4 По памяти.** Такты отрезка на нотах закрыты («по памяти»), падающих нот нет.
    После 3 хороших кругов — «Такты 1–4 выучены наизусть. Дальше: …» → «Дальше»
    переходит к следующему отрезку. У выученного отрезка зелёные точки.
11. Несколько плохих кругов подряд (много ошибок) → предложение вернуться на уровень ниже.
12. Любой уровень можно выбрать кнопками `0 … 4` вручную.
13. Сцепка `1+2` начинается сразу с уровня 2 (точки показывают уровень).

## Границы фрагментов

14. «Границы…» → такты раскрашены по фрагментам с номерами. Клик по такту делает его
    началом нового фрагмента, повторный клик убирает границу. Список отрезков меняется.
15. «Автоматически» возвращает разбивку по умолчанию, «Готово» (или Esc) — выход.
16. Закрой и открой пьесу (и приложение) — свои границы и уровни сохранились.

## Трудные такты

17. Переключатель «Трудные такты» (в обоих режимах) закрашивает красным такты, где были
    ошибки за 4 недели; чем больше ошибок, тем ярче. Подсказка при наведении — число ошибок.

## Экран «Прогресс»

18. Вкладка «Прогресс» (и плитка на главной). «Занятия по дням»: сегодня, за 7 дней,
    дней с занятиями; столбики за 4 недели. Поиграй пару минут — «сегодня» растёт
    (паузы до 30 с считаются игрой).
19. «Пьесы»: у каждой открытой пьесы полоса фрагментов, цвет — уровень (легенда ниже),
    «выучено N из M», число проходов, минуты, когда занимался. Клик по названию открывает пьесу.
20. «Трудные такты»: полоска тактов пьесы с красными клетками, «труднее всего: такт …».
21. «Тренажёр нот»: открытые ступени, число серий, ноты с процентом верных ответов.
22. На карточках в «Пьесах» под описанием — тонкая полоса фрагментов и «выучено N из M».
