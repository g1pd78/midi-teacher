# Чеклист этапа «Ю»: подсветка без провода

Пункты без пометки проверяются сразу, без железа. Пункты **[железо]** — когда соберёшь ленту и свисток по
`hardware/key-lights/README.md` (раздел 7). Для каждого пункта: ✅ работает / ❌ не работает + что произошло.

### Без железа

Ю-1. «Настройки → Подсветка клавиш» без платы: статус «не найдена», блока «Без провода» нет; остальное — как в
     этапе «Э» (переключатель, яркость, «Показывать мои нажатия», предпросмотр).
Ю-2. В архиве прошивки из сборки по-прежнему один файл `MIDI-Teacher-Lights-esp32s3.bin` — он для обеих плат.

### Свисток [железо]

Ю-3. Прошей обе платы (DevKitC-1 у ленты и Super Mini) этим файлом. Плата у ленты по кабелю, как раньше: статус
     «MIDI Teacher Lights — по проводу», блок «Без провода» с кнопкой «Связать с лентой». Огоньки, «▶ Проверить»,
     калибровка — работают, как в этапе «Э».
Ю-4. Старая прошивка (из этапа «Э») на плате: вместо кнопок — «Плата не сообщает о радио… обнови прошивку».
Ю-5. Питание платы у ленты, вариант 1: диод 1N5819 от «+» блока на 5V платы. Кабель к компьютеру отключён —
     плата работает от блока (горит светодиод питания).
Ю-6. Питание, вариант 2: плата у ленты в USB-зарядке. То же.

### Связка [железо]

Ю-7. Свисток в компьютере, лента питается от блока. Статус «MIDI Teacher Lights — по проводу». Выключи и включи
     блок ленты → «Связать с лентой» → «Ищу ленту…» → через 1–3 с «Связано», статус «по радио через свисток»,
     под ним «Сигнал хороший (−NN дБм) · потери N%». Появилась кнопка «Забыть ленту».
Ю-8. Через 3 минуты после включения ленты нажми «Связать заново» — «Лента не нашлась» (окно 2 минуты закрыто),
     прежняя связка не потерялась: статус снова «по радио…».
Ю-9. Выключи и включи компьютер и пианино (свисток и лента остаются связанными) — лента на связи сама, без
     повторной связки.
Ю-10. «Забыть ленту» → статус «по проводу», лента гаснет через 3 с. Свяжи заново (Ю-7).

### Работа по радио [железо]

Ю-11. Пьеса «Свободно»: огоньки следующего шага, вспышки верно/ошибка — без заметной задержки, как по проводу.
Ю-12. Режим «Ритм» в быстром темпе (120+): огоньки успевают, не запаздывают за нотами.
Ю-13. «▶ Проверить» и «Настроить по клавишам…» работают по радио; калибровка сохраняется на плате у ленты
      (выключи и включи её блок — огоньки над теми же клавишами).
Ю-14. Выдерни свисток — лента гаснет через 3 с. Вставь обратно — через пару секунд снова горит, статус
      «по радио…».
Ю-15. Выключи блок ленты — через 3 с статус «лента не отвечает» (жёлтым); включи — снова «по радио…».
Ю-16. Качество связи: свисток в USB на задней стенке компьютера и на удлинителе на виду — сравни сигнал и
      потери. Лента не должна мигать при игре.
Ю-17. Переход провод ↔ радио: подключи плату у ленты кабелем к компьютеру, пока свисток тоже в компьютере —
      приложение работает с одной из плат, лента горит; выдерни кабель — лента снова по радио.
