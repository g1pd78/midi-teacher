# Чеклист этапа «Э»: подсветка клавиш

Часть пунктов проверяется без ленты, по полоске «Сейчас на ленте» в настройках. Пункты с пометкой **[лента]** —
когда соберёшь ленту по `hardware/key-lights/README.md`. Для каждого пункта: ✅ работает / ❌ не работает + что
произошло.

### Без ленты

Э-1. «Настройки → Подсветка клавиш»: статус платы «не найдена», переключатель вкл/выкл, выход («Найти «MIDI Teacher
     Lights» сам»), яркость 5–60% (по умолчанию 25%), галочка «Показывать мои нажатия», кнопки «Проверить» и
     «Настроить по клавишам…» неактивны без платы.
Э-2. Полоска «Сейчас на ленте» в настройках: нажми клавишу на NPK — над ней загорается огонёк; отпусти — гаснет.
     Сними «Показывать мои нажатия» — при нажатии ничего не горит.
Э-3. Поставь яркость 40% и сними «Показывать мои нажатия», закрой и снова открой приложение — настройки те же.

### Плата и прошивка [лента]

Э-4. Прошивка из браузера (esptool-js, файл из архива MIDI-Teacher-Lights-esp32s3-<sha>) → RST → в Windows
     появилось устройство «MIDI Teacher Lights» (Диспетчер устройств → «Звуковые, игровые и видеоустройства»).
Э-5. «Настройки → Подсветка клавиш»: статус — «MIDI Teacher Lights». «▶ Проверить» — огонёк пробегает по ленте
     слева направо за ~2,5 с.
Э-6. «Настроить по клавишам…»: стрелками огонёк над самой левой «ля» → нажми её; над самой правой «до» → нажми;
     затем любая клавиша — огонёк точно над ней (проверь «до», «фа-диез», крайние). Выдерни и вставь USB — после
     появления платы калибровка та же.
Э-7. Яркость: двигаешь ползунок — лента сразу ярче/тусклее; на 60% не слепит, блок питания не греется.

### Что горит [лента]

Э-8. Пьеса «Свободно», ожидание: горят клавиши следующего шага — правая рука голубым, левая янтарным; верная нота —
     короткая зелёная вспышка, ошибка — красная.
Э-9. Режим «Ритм»: клавиши текущего шага ярко, следующего — тускло заранее.
Э-10. Упражнения (гаммы, «пять пальцев») и «Разучить» — так же, как в пьесе.
Э-11. Тренажёр нот с подсказкой — горит загаданная клавиша; аккорды — звуки аккорда; «Слух» — после верного ответа
      звуки задания зелёным.
Э-12. «Джем»: гамма тускло, звуки аккорда ярко. «Код»: «моя партия» — клавиши подсказки.
Э-13. Мои нажатия: на главной — яркий белый огонёк над нажатой клавишей; в пьесе — тусклый (не мешает подсказкам).
Э-14. 10 минут без игры — лента гаснет; нажми клавишу — снова горит. Закрой приложение — лента гаснет через 3 с.
Э-15. Выключи подсветку переключателем — лента гаснет сразу; включи — снова горит.
