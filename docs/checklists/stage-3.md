# Чеклист этапа 3: падающие ноты, темп, цикл, режим ритма

Проверяется на Windows с цифровым пианино / MIDI-клавиатурой. Для каждого пункта:
✅ работает / ❌ не работает + что произошло.

## Падающие ноты (режим «Ожидание»)

1. Открой «Оду к радости». → Под нотами тёмная полоса с падающими нотами над клавиатурой:
   правая рука голубая, левая янтарная, ноты другой руки — серые.
2. Ноты подъезжают к клавиатуре и **замирают** на линии, пока ты не сыграешь нужное.
   Сыграл — плавно подъезжают следующие.
3. Сыгранные ноты становятся зелёными (на стане и в падающих).
4. «Падающие ноты» выкл (или клавиша H) → полоса пропадает, ноты на стане крупнее.

## Темп

5. Ползунок «Темп» 30–120%, рядом удары в минуту. Клавиши + / − меняют на 5%.
6. В «Ожидании» темп влияет на шаги, которые проходят сами (только другая рука).

## Цикл

7. Клик по такту на нотах, затем по другому такту → такты между ними выделены голубым,
   в полях «Такты» появились номера, курсор перешёл в начало отрезка.
8. Shift+клик расширяет выделение. Поля «с / по» меняют отрезок, «сбросить» или Esc — убирают.
9. «Ожидание» + цикл: после последней ноты отрезка — снова первая, вверху сообщение
   «Круг N: без ошибок» / «ошибок: K».

## Режим ритма

10. «Ритм» → кнопка «▶ Старт» (или пробел).
11. «Отсчёт» вкл → перед началом щелчки на один такт (сильная доля выше), затем музыка.
    Выкл → без щелчков, пауза ~1 с перед первой нотой.
12. «Метроном» вкл → щелчки на каждую долю во время игры. Щелчки слышны из колонок/наушников
    компьютера (даже если ноты звучат через пианино).
13. Ноты падают непрерывно в заданном темпе; вторая рука звучит в темпе (если включена).
14. Сыграл вовремя → нота зелёная; неточно (> 120 мс) → жёлтая; не сыграл → красная;
    лишняя нота — вспышка красной клавиши. Музыка не останавливается.
15. В конце — «Сыграно в темпе»: процент сыгранных нот, отклонение ±мс, «точно / нормально /
    неточно / пропущено / лишних», подсказка «спешишь / опаздываешь», трудные такты.
16. «Ритм» + цикл → отрезок повторяется без паузы, после каждого круга — «Круг N: X% нот, ±Y мс».
17. «■ Стоп» (или пробел) останавливает; смена руки/темпа/цикла во время игры тоже останавливает.
18. Субъективно: щелчки метронома и падающие ноты совпадают с тем, что звучит; ноты
    не «плывут» относительно звука.
