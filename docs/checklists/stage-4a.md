# Чеклист этапа 4а: аппликатура

Проверяется на Windows с цифровым пианино / MIDI-клавиатурой. Для каждого пункта:
✅ работает / ❌ не работает + что произошло.

## Цифры пальцев

1. Открой «Оду к радости» («Разучить», уровень 0 или 1). Над каждой нотой правой руки
   и под каждой нотой левой — цифра пальца.
2. Цифры из файла — чёрные, подобранные автоматически — серые. У первой ноты «Оды» — 3
   (из файла), дальше 3 4 5 | 5 4 3 2 | 1 1 2 3 …
3. «Менуэт соль мажор»: в файле пальцев нет — все цифры серые. Пальцы выглядят разумно:
   позиции без лишних растяжек, подкладывание первого пальца в гаммообразных местах.
4. В падающих нотах внизу — цифра пальца (у подобранных бледнее).
5. На подсвеченной клавише (какую нажать сейчас) — крупная цифра пальца.
6. Уровни «Разучить»: на 0, 1, 2 цифры видны; на 3 «В темпе» и 4 «По памяти» — скрыты
   (и на стане, и в падающих, и на клавишах).
7. «Свободно»: цифры видны при включённом переключателе «Аппликатура», выключил — пропали.

## Ручная правка («Пальцы…»)

8. Кнопка «Пальцы…» (в «Разучить» — рядом с «Границы…», в «Свободно» — в строке
   переключателей). Появляется подсказка с легендой цветов.
9. Клик по ноте — нота выделяется фиолетовым. Клавиши 1–5 ставят палец — цифра становится
   синей. Соседние серые цифры могут пересчитаться под твой палец.
10. 0 / Delete / Backspace — правка убрана, у ноты снова палец из файла или подобранный.
11. ← / → — соседняя нота (по времени). Esc или «Готово» — выход из режима.
12. Правка ноты с пальцем из файла заменяет его (цифра синяя).
13. Закрой пьесу, открой снова (и перезапусти приложение) — правки на месте.
14. Пока открыт режим «Пальцы…», клик по нотам не выбирает фрагмент/такты, а цифры 1–3
    не переключают руки.

## Названия нот

15. На уровне 1 (руки отдельно) названия нот подписаны только у нот той руки, которая
    сейчас играет, — нотная строка стала крупнее, чем на этапе 4.
