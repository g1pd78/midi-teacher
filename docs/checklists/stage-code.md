# Чеклист этапа «Код (Strudel)»

Проверяется на Windows с цифровым пианино (NPK) и, где сказано, с MIDI-клавиатурой. Для каждого пункта:
✅ работает / ❌ не работает + что произошло. Звук кода идёт из колонок компьютера (WebAudio), пианино звучит само.

## Вкладка «Код»

Ш-1. Вкладка «Код» (после «Студии»). При первом открытии — «Первый трек»: барабаны, бас и мелодия. ▶ «Играть»
     (или Ctrl+Enter) — звучит; в коде подсвечиваются звучащие места мини-нотации. ■ «Стоп» (Ctrl+.) — тишина.
Ш-2. Правка во время игры: поменяй `hh*8` на `hh*16` → «▶ Применить» (Ctrl+Enter) — меняется без остановки.
Ш-3. Опечатка (например, `s("bd").lpff(800)`) — внизу «Ошибка в коде» по-русски с исходным текстом; звук не обрывается
     на прошлой версии кода, вкладка не ломается.
Ш-4. Звук без интернета (Wi-Fi выключен): `bd sd hh oh cp`, `piano`, `gm_acoustic_bass`, `gm_epiano1`, `sawtooth`,
     `triangle` — всё звучит. Первая нота нового инструмента может опоздать на долю секунды — со второго круга ровно.
Ш-5. Треки — файлы `Документы\MIDI Teacher\Код\*.js` («Папка «Код»»): «+ Новый», «Переименовать», «Удалить». Правка
     сохраняется сама (через секунду). Открой файл в Блокноте, измени и сохрани — при возвращении в окно приложения
     вкладка загружает новую версию.
Ш-6. Примеры слева создают новый трек: «Первый бит», «Хаус», «Эмбиент» звучат; «MT» — пример с функциями только
     для MIDI Teacher.

## Свои сэмплы и стандартные наборы

Ш-7. Положи WAV в `Документы\MIDI Teacher\Сэмплы\whatUneed\1.wav`, `2.wav` → «Обновить звуки» → пример «Свои сэмплы»:
     `s("whatUneed:0 ~ whatUneed:1 ~")` звучит. Файл прямо в «Сэмплы» (`клап.wav`) — звук `клап`.
Ш-8. Свои записи — банк `rec`: запись с гитары (вкладка «Гитара») или WAV трека доступны как `s("rec:0")`.
Ш-9. «Стандартные наборы Strudel (интернет)» включены: `s("bd sd").bank("RolandTR909")` звучит как драм-машина
     (при первом запуске — с задержкой на скачивание). Выключи интернет — те же звуки работают из кэша.

## Играть поверх кода

Ш-10. Пример «Играй мелодию»: ▶, в панели «Моя партия» = melody — мелодия не звучит, её клавиши горят на экранной
     клавиатуре (ярко — сейчас, бледно — следом). Играй на NPK: точно — зелёная вспышка, близко — жёлтая, мимо —
     красная; справа процент «вовремя».
Ш-11. После «Стоп» — итог: точно/близко/пропущено/лишних и советы (спешишь/опаздываешь). Ровная игра — 85% и выше.
Ш-12. «Засчитывать в любой октаве» — мелодия октавой выше тоже засчитывается.
Ш-13. Пример «Повтори за мной»: цикл — фраза звучит, следующий цикл — подсветка; повтори на клавишах — засчитывается.
     То же из панели: обычная партия в «Повтори за мной».
Ш-14. Пример «Импровизация на блюз»: зелёные клавиши — звуки аккорда, голубые — лад; «Сейчас: …» меняется по
     аккордам. После «Стоп» — сколько нот в аккорде, в ладу, мимо, и советы.
Ш-15. Свой трек без `harmony()`: «Импровизация: подсветить аккорд и лад» — аккорд по нотам кода, лад определён сам
     (или впиши «A:minor» и аккорды «Am F C G»).
Ш-16. MIDI-клавиатура: «Что присылает устройство» — нажатия и номера ручек (CC). Пример «Ручки и клавиши»: ручка
     CC 74 открывает фильтр, клавиша транспонирует бас (`kb().note`). «Транспонировать клавишей» в панели — то же
     без правки кода.

## Перевод

Ш-17. Код играет → «● Записать рифф» (2 такта) → «Начать» → сыграй рифф со следующего такта → в окне `note("…")` →
     «Вставить в код» — рифф звучит партией `riff`, ритм как сыграно (по сетке). Без игры кода — 4 щелчка отсчёта.
Ш-18. «В ноты / MIDI»: партия → «Пьеса с нотами» — в «Пьесах» появилась пьеса со станом; «В Студию» — трек Студии;
     «MIDI-файл» — путь к файлу.
Ш-19. «WAV» (8 циклов) — файл в `Документы\MIDI Teacher\Треки`, звучит как код. «С моей игрой» — твои нажатия
     последнего запуска звучат роялем поверх.
Ш-20. «В код» с других экранов: грув в «Барабанах» («Открыть во вкладке «Код»» над упражнением), песня по буквам
     («В код» в списке «Аккорды»), стиль джема («Открыть кодом…»), упражнение («Упражнения») — открывается новый трек,
     звучит так же; у упражнения руки — мои партии.
Ш-21. «Для strudel.cc» — в буфере код без `.you()`, `echo()`, `harmony()`, `kb()`; вставь на strudel.cc — звучит
     (оригинальными драм-машинами). Свои сэмплы — строка `samples({…}, "https://raw.githubusercontent.com/…")`.

## Курс «Музыка кодом»

Ш-22. «Курс» → направление «Музыка кодом»: 6 модулей, 21 урок. Урок: слева теория и задание, справа редактор.
     «✓ Проверить» со стартовым кодом — «Пока не то…»; «Подсказка» — по одной; «Показать ответ» → «Проверить» —
     «Верно» → «Дальше», урок отмечен ✓.
Ш-23. Уроки 17–19 («Своя партия», «Импровизация», «Повтори за мной») засчитываются после «Стоп» по игре на NPK.
Ш-24. Уроки курса появляются шагом дня на главной и в дневнике (`code-…`); в плане из YAML шаг `code: 5`.
Ш-25. Пометка урока «работает и на strudel.cc» / «только в MIDI Teacher».
