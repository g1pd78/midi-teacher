# Чеклист: ещё три пьесы

Мелодии записаны по памяти (нотные сайты из окружения разработки недоступны), поэтому главное — **сверить их на
слух**. Для каждого пункта: ✅ работает / ❌ не так + что именно (номер такта и как должно быть). Самый точный
способ поправить — сыграй мелодию правильно в «Свободно» с записью (●) → сохрани в MIDI и пришли файл.

П2-1. «Пьесы»: в списке после «Калинки» — «Ах вы, сени, мои сени», «В саду ли, в огороде», «Сурок» (уровень
      «Начальный»). Каждая открывается, ноты на стане, аппликатура видна.
П2-2. «Ах вы, сени»: нажми «▶ Послушать» (или сыграй по нотам) — мелодия узнаётся? Отметь такты, где не так.
      Мелодия идёт дважды (такты 1–8 и 9–16).
П2-3. «В саду ли, в огороде»: то же. Затакт — одна восьмая «соль», куплет дважды.
П2-4. «Сурок» (Бетховен): то же. Затакт «ми», дважды.
П2-5. Левая рука в каждой пьесе звучит к месту (не режет слух); в «Свободно» обеими руками режим ожидания
      проходит до итога.
