# Чеклист этапа 2: интерактивный нотный стан

Проверяется на Windows с цифровым пианино и MIDI-клавиатурой (звук второй руки —
через пианино или встроенный синтезатор, как настроено в «Устройства и звук → Звук приложения»).
Для каждого пункта: ✅ работает / ❌ не работает + что произошло.

## Библиотека

1. Вкладка «Пьесы» (или плитка на главной).
   → Разделы «Встроенные» (Ода к радости, Менуэт соль мажор) и «Мои файлы».
2. В «Моих файлах» показан путь папки (`Документы\MIDI Teacher`). «Открыть папку» открывает её в Проводнике.
3. Перетащи файл `.musicxml` или `.mxl` в окно.
   → Появляется рамка «Отпусти, чтобы добавить», после — сообщение «Добавлено: …», файл в списке.
4. «Добавить файл…» — выбор файлов через диалог, результат тот же.
5. Файл `.mid` в папке показан серым: «MIDI-файлы можно будет играть позже».

## Ода к радости

6. Открой «Оду к радости». → Ноты в одну строку, два стана, цифры аппликатуры над нотами.
   Первая нота (ми) голубая, на клавиатуре подсвечена ми первой октавы.
7. Режим «Правая»: играй мелодию. → Курсор ждёт правильную ноту, строка сама прокручивается,
   текущее место примерно в левой четверти.
8. «Вторая рука звучит» включено → на первой ноте каждого такта вместе с тобой звучит бас (до/соль малой октавы).
   Выключи → бас не звучит.
9. Неправильная клавиша → клавиша вспыхивает красным, курсор не двигается.
10. Доиграй до конца. → «Пьеса сыграна»: число ошибок, время, трудные такты.
11. «Левая»: теперь нужно играть бас, мелодию играет приложение. Шаги без баса проходят сами.
12. «Обе»: курсор ждёт обе руки (ноты правой — голубые, левой — янтарные; порядок нажатия внутри аккорда любой).

## Менуэт

13. Открой Менуэт, «Обе». → Первый шаг: ре второй октавы + аккорд соль–си–ре в левой.
14. В такте 25 левая рука: си под лигой → повторно нажимать не нужно.
15. «Страницы» → ноты в несколько строк, при переходе на следующую строку она прокручивается сама.

## Подсказки и управление

16. «Названия нот» → под нотами до-ре-ми (или C-D-E, если так выбрано в настройках).
17. «Аппликатура» выкл → цифры пальцев пропадают.
18. «Подсветка клавиш» выкл → нужные клавиши на экранной клавиатуре не подсвечиваются.
19. Горячие клавиши: 1/2/3 — рука, R — заново, Esc — к списку.
20. Если калибровка клавиатуры (мастер или настройки) уже есть и пьеса шире — появляется предупреждение.
21. Переключение «Строка/Страницы» и «Названия нот» не сбрасывает текущее место в пьесе.
