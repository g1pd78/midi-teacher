# Чеклист этапа «Щ»: ладони, доработки «Кода», новые пьесы

Проверяется на Windows с цифровым пианино (NPK); пункты про «Код» — со звуком из колонок компьютера. Для каждого
пункта: ✅ работает / ❌ не работает + что произошло.

### Схема ладоней

Щ-1. «Ода к радости» → «Свободно» → переключатель «Ладони» (рядом с «Аппликатура») — по бокам экранной клавиатуры
     две ладони: левая слева, правая справа, большие пальцы смотрят к клавиатуре, на пальцах цифры 1–5.
Щ-2. Палец следующей ноты горит цветом руки (правая — голубой, левая — оранжевый), палец ноты после неё — бледно.
     Цифра совпадает с цифрой над нотой и на подсвеченной клавише.
Щ-3. Сыграй верную ноту на NPK — её палец коротко вспыхивает зелёным. Не ту клавишу — у руки красная рамка.
Щ-4. «Обе» руки: горят пальцы обеих ладоней (аккорд — несколько пальцев сразу). «Ритм» — пальцы идут в темпе.
Щ-5. Упражнения: гамма или «пять пальцев» — тот же переключатель, ладони показывают аппликатуру упражнения.
Щ-6. Выключи «Аппликатуру» — «Ладони» неактивны и схема пропадает. Узкое окно (меньше ~900 px) — схема прячется.

### Вкладка «Код»

Щ-7. «Первый трек» → ▶ — под редактором «Нотная лента»: ноты партий цветами (барабаны снизу строками bd/sd/hh,
     бас, мелодия), посередине линия «сейчас», лента едет. Галочка «Нотная лента» справа в панели — убирает/
     возвращает (запоминается).
Щ-8. «Играй мелодию», моя партия melody — её ноты на ленте контуром, твои нажатия на NPK — белыми точками.
Щ-9. Допиши в конец строки `._pianoroll()` → Ctrl+Enter — под строкой появляется маленький пиано-ролл. Так же
     `._scope()` (осциллограф) и `._punchcard()`.
Щ-10. `.lpf(slider(800, 200, 4000))` — в коде ползунок, двигаешь — фильтр меняется на лету.
Щ-11. `.pianoroll()` без подчёркивания — пиано-ролл рисуется полупрозрачно на фоне редактора (не на всё окно),
      код читается и редактируется.
Щ-12. Начни печатать `s("gm_ac` — список подсказок звуков (gm_accordion, gm_acoustic_bass…); Enter вставляет.
      `s("` и первая буква своего сэмпла — он тоже в подсказках.
Щ-13. Печатай `.ro` — подсказки функций (room, rev…), справа справка: описание по-русски и пример. Для редкой функции —
      английская справка Strudel. У `you`, `echo`, `harmony`, `kb` — пометка «только в MIDI Teacher».
Щ-14. Наведи мышь на имя функции в коде (`lpf`, `every`) — всплывает та же справка.
Щ-15. Перетащи WAV из проводника на вкладку «Код» — подсветка «Отпусти, чтобы добавить сэмплы» → окно «Имя звука»
      (по умолчанию имя файла латиницей) → OK: файл в `Документы\MIDI Teacher\Сэмплы\<имя>`, в коде у курсора
      `s("<имя>:0")`, ▶ — звучит.
Щ-16. Перетащи папку с несколькими WAV — все файлы в одну папку звука: `s("<имя>:0 <имя>:1 <имя>:2")`.
Щ-17. Перетащи не звук (например, .txt) — подсказка «Перетащи звуковые файлы…», ничего не копируется.

### Новые пьесы

Щ-18. «Пьесы» → «К Элизе (полностью)» (уровень «Продвинутый»): вся пьеса — тема, фа-мажорная середина с 32-ми,
      эпизод с аккордами и хроматическим пассажем триолями, тема. Левая рука переходит в скрипичный ключ там, где
      в оригинале. Упрощённая «К Элизе» осталась.
Щ-19. «Прелюдия до мажор (полностью)»: 35 тактов, в левой руке два голоса (выдержанный бас и нота узора) — «Обе»
      в режиме ожидания проходят до последнего аккорда.
Щ-20. «Гитара» → «Пьесы» → «Испанский романс»: ми минор, потом ми мажор, в каждой доле триоль (табы и ноты с
      цифрой 3), бас на первую долю; пальцы p, a, m, i над нотами. Играется по звуку гитары, как остальные пьесы.
Щ-21. «Курс» → фортепиано: новый модуль «Оригиналы» (уроки 19–21: Прелюдия целиком, «К Элизе» по рукам и целиком).
      Гитара: в «Классической гитаре» — урок «Испанский романс».
