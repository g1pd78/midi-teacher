# Чеклист этапа «Курс: путь обучения»

Проверяется на Windows: фортепиано (клавиатура), гитара и бас (вход звука, «Слушать вход» включён), барабаны (пэды).
Для каждого пункта: ✅ работает / ❌ не работает + что произошло.

## Экран курса

Х-1. Вкладка «Курс» — сразу после «Главной». Переключатель «Фортепиано / Гитара / Бас / Барабаны»; выбор
     сохраняется после перезапуска.
Х-2. Программа: фортепиано — 6 модулей по 3 урока (18 уроков), гитара — 6×3 (18), бас — 5×3 (15), барабаны — 4×3 (12).
     У модуля — название и описание, у урока — название, цель и «Шагов: N из M · сейчас / открыт / пройден».
Х-3. Сверху — полоса «Уроков пройдено: N из M» и кнопка «▶ Начать: …» (потом «▶ Продолжить: …») — открывает текущий
     урок.
Х-4. На свежем профиле открыт только урок 1; остальные серые — «Откроется после предыдущего урока», не нажимаются.

## Урок

Х-5. Урок: 4–8 шагов (теория, упражнения, тренажёры, пьеса или песня, слух, джем). Текст «Урок — около 20–30 минут;
     шаги можно проходить в любом порядке и за несколько дней», счётчик «N / M» вверху.
Х-6. Следующий незасчитанный шаг выделен, кнопка «▶ Начать урок» / «▶ Продолжить» запускает его. Любой другой шаг
     запускается своей кнопкой «▶» (засчитанный — «Ещё раз»).
Х-7. Шаг открывает то же задание, что в разделе приложения (упражнение, тренажёр нот нужной ступени, чтение с листа,
     ритм, аккорды, гриф, слух, «Найди основной тон», «Повтори за мной», урок джема, пьеса, песня по буквам).
     Кнопка «назад» везде подписана «← Курс» и возвращает в урок.
Х-8. Шаг «Теория»: карточка с примером и кнопка «Понятно» — шаг сразу засчитан (✓).
Х-9. Шаг засчитывается по тем же правилам, что в разделе: упражнение, чтение, ритм, слух и т. п. — «Засчитано»
     в итоге; тренажёр нот — ступень пройдена (90% и быстрее 2 с); пьеса и песня по буквам — сыграна в режиме ожидания
     с ошибками не больше чем в 15% нот. Результат, полученный раньше в самом разделе, тоже считается.
Х-10. Шаг «Пьеса» правой (левой) рукой: вторую руку играет приложение; подсказка «Играй правой рукой.». Режим
     ожидания включён сразу; курсор не сбрасывается от нажатий.
Х-11. Все шаги засчитаны — «Урок пройден ✓» и кнопка «Следующий урок: …»; в списке урок с ✓, следующий открыт.
Х-12. Повторение: со второго урока сверху строка «↻ Повторение: … — по желанию, каждый день другое» — одно из уже
     засчитанных заданий прошлых уроков. На следующий день — другое.

## «Я это уже умею»

Х-13. У открытого незасчитанного модуля — кнопка «Я это уже умею»: 3 задания из уроков модуля. Все три засчитаны —
     «Модуль засчитан ✓ — следующий открыт».
Х-14. После этого уроки перескоченного модуля открыты (можно пройти), а текущим становится первый урок следующего
     модуля.

## Главная

Х-15. «Занятие на сегодня»: первый шаг «Урок курса N» — «‹название урока›», после первых шагов — «шагов сегодня: k».
     Нажатие открывает текущий урок курса.
Х-16. Шаг «Урок курса» отмечается выполненным, когда сегодня сыграно не меньше трёх разных шагов курса.

## Прочее

Х-17. Гитара и бас в курсе берут строй с вкладки «Гитара»; барабанные шаги — с пэдов. Шаги джема и «Повтори за
     мной» у барабанщика идут на клавиатуре.
Х-18. Разделы «Упражнения», «Тренажёры», «Гитара», «Барабаны» — как раньше; кнопки «назад» там прежние («← Слух»,
     «← Аккорды», «← Ступени» и т. п.).
