# Чеклист мини-этапа «Интерфейс: упражнения на каждый день»

Проверяется на Windows. Для каждого пункта: ✅ работает / ❌ не работает + что произошло.

## Список гитарных упражнений

С-1. «Упражнения» → «Гитара» (и «Бас»): закрытые разделы — одной строкой «откроется после «…»», без описания.
С-2. Клик по заголовку открытого раздела (▾/▸) сворачивает и разворачивает его. Перезапусти приложение —
     свёрнутые остались свёрнутыми. Паучок можно свернуть, только если сам этого захочешь.
С-3. У каждого открытого упражнения — звёздочка ☆. Нажми → ★ (жёлтая), упражнение появляется в «На сегодня»
     со звёздочкой, первым в списке. Повторное нажатие убирает. Звёздочки сохраняются после перезапуска.
С-4. Упражнение, сыгранное сегодня в темпе (результат записан, даже если не засчитан), обведено синей рамкой; в заголовке раздела —
     «сегодня N». На следующий день рамки нет.
С-5. «На сегодня»: ★-упражнения, паучок «по кругу» — каждый день другой из уже засчитанных вариантов, — и
     следующий новый паучок, плюс одно упражнение из других разделов. В течение дня список не меняется.
С-6. У группы, где открыто больше одного варианта (например, паучок 1-2-3-4 после первого зачёта), кнопка
     «▶ Все подряд» → все открытые варианты один за другим, вверху «Подряд: 1 из N», кнопка «Дальше».

## Гриф и песни

С-7. Гриф (тренажёр грифа, экран пьесы на гитаре, тренажёр аккордов): названия открытых струн слева не
     перекрываются отметками; отметка открытой струны — между подписями и порожком, на самой струне.
С-8. Тренажёр гитарных аккордов: открытые струны аккорда отмечены на грифе зелёным ○.
С-9. «Тренажёры» → «Аккорды» → «Гитара»: сузь окно — схемы аккордов песни и выбор боя переносятся на
     следующую строку, а не сжимаются.

## Прочее

С-10. Фортепианные упражнения и остальное — как раньше.
