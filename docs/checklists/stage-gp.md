# Чеклист этапа «Guitar Pro и текстовые табы»

Проверяется на Windows. Нужны 2–3 файла Guitar Pro (.gp3, .gp4, .gp5 или .gp из Guitar Pro 7–8) — скачай сам
с любого сайта табов: лучше песня с несколькими партиями (гитара, бас, барабаны), а также пара текстовых табов
со страницы с табами (просто скопировать текст). Для гитарных пунктов — гитара или бас через Real Tone Cable,
для барабанов — пэды. Для каждого пункта: ✅ работает / ❌ не работает + что произошло.

## Guitar Pro

Н-1. «Пьесы» → «Добавить файл…» (или перетащи в окно) файл Guitar Pro → карточка с пометкой «Guitar Pro».
     В окне выбора файлов видны .gp3, .gp4, .gp5, .gp.
Н-2. Открой → вверху «Исполнитель — Песня» и строй партии; кнопки партий с их названиями из файла (если партий
     больше четырёх — выпадающий список с типом: гитара, бас, фортепиано, мелодия, барабаны).
Н-3. Гитара и бас — табами с ладами из файла (строй и каподастр — тоже из файла). Приёмы над нотами: H, P, слайды,
     бенды, вибрато, PM, флажолеты, X (глушёные), T/S/Pop; названия аккордов и текст из файла. **Запиши**, что не так.
Н-4. Части песни (маркеры Guitar Pro: «Intro», «Verse», «Chorus»…) — подписи над тактами и двойная черта перед
     новой частью; в режиме «Разучить» фрагменты делятся по частям.
Н-5. Повторы, вольты, D.S./D.C., Coda и Fine развёрнуты: такты идут подряд в том порядке, в каком звучат
     в Guitar Pro. **Запиши**, если порядок не совпадает с Guitar Pro (или сайтом, где играет таб).
Н-6. Смены темпа: «♩ = …» над тактом; песня играет в темпе файла. Ускорения и замедления внутри такта сглажены
     до среднего темпа такта.
Н-7. Остальные партии звучат аккомпанементом (переключатель «Аккомпанемент»): играешь гитару — слышны бас,
     барабаны, клавишные; у каждой партии свой инструмент из файла.
Н-8. Партия фортепиано (или клавишных, мелодии, вокала) → обычные ноты и клавиатура: две строки у фортепиано
     (правая и левая рука), у мелодии — одна строка (правая рука). Знаки при ключе — из файла.
Н-9. Слова песни (если есть в файле) — под нотами; на повторе — следующий куплет.
Н-10. Партия барабанов → ударный стан, дорожка по барабанам и пэды; играется на пэдах, как барабаны из MIDI.
Н-11. Строй партии отличается от твоего (например, бас на тон ниже) → плашка «Перестроить / Переложить табы»,
      как у песен Rocksmith.
Н-12. Второй голос в табах (пальцевая игра: бас и мелодия) показывается и засчитывается.
Н-13. Режимы работают как обычно: «Свободно», ожидание и в темпе, темп, циклы, «Ноты над табами».
Н-14. Файл Guitar Pro 6 (.gpx) не поддерживается — понятное сообщение или файл не добавляется.

## Текстовые табы

Н-15. «Пьесы» → «Вставить таб…» → окно с полем для текста. Вставь таб со страницы (строки `e|---0---3---|`).
      Под полем: «Гитара, 6 струн · Стандарт (E) · тактов: N · нот: M» и предпросмотр табов.
Н-16. Строй — по буквам слева (D|… внизу → Drop D), «Capo 2» в тексте → каподастр 2. Бас (4 строки) — 4 струны.
Н-17. Ритм: «по расстоянию» (длительность по промежуткам между цифрами в такте) или «ровно восьмыми /
      шестнадцатыми / четвертями». Поменяй — предпросмотр меняется. **Запиши**, какой вариант лучше работает
      на твоих табах.
Н-18. Темп и размер — из полей (по умолчанию — из текста, если там есть «Tempo 100» или «3/4»).
Н-19. «Сохранить в библиотеку» → карточка «Таб» с твоим названием; файл .txt в папке библиотеки, первая строка —
      темп, размер и ритм. Открывается и играется как обычная пьеса на гитаре/басе.
Н-20. Хаммеры (h), пулл-оффы (p), слайды (/ \), бенды (7b9), вибрато (~), глушёные (x) — подписи над нотами.
Н-21. Свой .txt с табом можно добавить файлом; .txt без табов в библиотеке не появляется.
Н-22. Текст без табов → «не нашёл строк таба…», кнопка «Сохранить» недоступна.

## Прочее

Н-23. Песни Rocksmith, MusicXML, MIDI, пьесы на фортепиано, барабаны, студия работают как раньше.
