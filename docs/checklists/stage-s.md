# Чеклист этапа «Студия»: свой трек из дорожек

Проверяется на Windows с пианино/клавиатурой (пэды и гитара — по желанию).
Для каждого пункта: ✅ работает / ❌ не работает + что произошло.

## Трек с нуля

С-1. В шапке вкладка «Студия»: описание, «+ Новый трек», «Из MIDI-песни…», «Мои треки».
С-2. «+ Новый трек»: название, темп, размер (4/4, 3/4, 2/4, 6/8), тактов → «Создать». Открылся трек
     с одной дорожкой «Клавишные».
С-3. «● Записать «Клавишные»» → отсчёт такта щелчками («отсчёт…»), дальше метроном и «такт 1 · доля 1»,
     курсор едет по ленте. Сыграй пару тактов → «■ Стоп» (или пробел) → «Записан дубль: нот N»,
     на ленте появились ноты, у дорожки «Дубль 1».
С-4. «▶ Играть» — звучит записанное (роялем приложения), курсор едет; в конце трек останавливается сам.
С-5. «+ дорожка: Бас» → инструмент «Бас-гитара». Выбери её (кружок слева) → «● Записать «Бас»».
     Во время записи звучат клавишные, ты играешь бас (на клавиатуре — басовым звуком или гитарой по
     звуку). После стопа — обе дорожки звучат вместе, каждая своим инструментом.
С-6. «+ дорожка: Барабаны» → запись на пэдах. Барабаны звучат барабанами.
С-7. Запиши дорожку ещё раз → «Дубль 2». В списке дублей можно выбрать, какой звучит.
С-8. «Переписать такты» → например 3–4 → «● Записать»: запись начинается с такта 2 (вход), звучит
     и старый дубль вне куска; сохраняется новый дубль «Дубль N (такты 3–4)» — в нём старое вне куска
     и новое внутри. На ленте кусок подсвечен красным.
С-9. Сетка у дорожки: «по восьмым» / «по шестнадцатым» / «по триолям», сила 20–100% → ноты на ленте
     встают ровнее, звучит ровнее. «как сыграно» — всё как было (запись не меняется).
С-10. Громкость дорожек, «M» (выключить), «S» (соло — звучат только дорожки с «S»).
С-11. Инструмент дорожки меняется (электропиано, орган, струнные, гитары…) — звучит выбранным.
С-12. «с такта N» и клик по ленте — воспроизведение с этого такта.
С-13. Темп меняется только в пустом треке (потом поле серое — чтобы ноты не съехали с тактов).
С-14. Название трека, имена дорожек правятся; «← Треки» → трек в «Мои треки», открывается снова
      со всеми дорожками и дублями (сохраняется сам).

## Трек из MIDI-песни

С-15. «Из MIDI-песни…» → список MIDI из «Моих файлов» → выбери песню. Дорожки песни — дорожками трека,
      у каждой дубль «Оригинал», инструменты как в песне.
С-16. «▶ Играть» — звучит песня целиком.
С-17. Выбери дорожку (например, барабаны или бас) → «● Записать»: остальные дорожки звучат, ты
      играешь свою партию. Новый дубль — с оценкой «N% к оригиналу». **Запиши**, насколько оценка
      похожа на правду.
С-18. Переписывай партии по одной — в итоге песня целиком в твоём исполнении. Выбор между
      «Оригинал» и своими дублями — в списке дублей.

## Экспорт

С-19. «Сохранить MIDI» → «MIDI сохранён в «Мои файлы»: <трек>.mid». Файл открывается в MuseScore/DAW:
      дорожки с именами и инструментами, барабаны на 10-м канале. В приложении открывается как пьеса.
С-20. «Сохранить WAV» → «Свожу…» → «WAV сохранён: …\Документы\MIDI Teacher\Треки\<трек>.wav».
      Файл играет в любом плеере: все дорожки, рояль и инструменты GM, громкости как в микшере.

## Прочее

С-21. Пьесы, упражнения, барабаны, гитара работают как раньше.
С-22. Шапка помещается в одну строку и на узком окне (1366 px).
